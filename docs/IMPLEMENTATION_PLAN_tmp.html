Agent Sidecar Implementation Plan

Agent Sidecar is provider-agnostic middleware for coding agents. It observes compact sanitized trajectory slices, detects wasted tokens, loops, risky edits, weak planning, context bloat, and missing validation, then returns targeted interventions.

The normal LLM provider call continues directly to OpenAI, Anthropic, local models, or the user's chosen provider. Agent Sidecar does not need provider API keys, full raw system prompts, unrelated source code, or files the agent did not read.

Boundary

Agent loop -> Agent Sidecar SDK/middleware -> normal provider call continues directly
Sidecar API receives only sanitized trajectory slices and returns interventions.
